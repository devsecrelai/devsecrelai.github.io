## Know what you ship

An inventory of source repositories, dependencies, build inputs, and deployed artifacts gives responders a place to start when a vulnerability is disclosed.

{% include toc.html %}

## Protect the build

Use isolated builds, pinned dependencies, least-privilege CI tokens, and protected release workflows. Generate provenance or attestations where your ecosystem supports them.

## Verify before release

Require code review, automated tests, dependency checks, and artifact integrity checks. Security controls should provide feedback early enough that delivery teams can act on it.
